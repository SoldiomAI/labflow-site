Changelog

Software you can trust ships on a visible cadence. Every release below was published as a Windows installer with SHA-256 checksums and a software bill of materials. Licence holders receive update notices by email; updating preserves your database and settings.

1.7.0August 2026Current
  • Ask your documents: plain-language questions answered from inside your SOPs and scanned documents — cited passages, click to open the source, fully offline (English and Arabic)
  • AI assistant gained a read-only document-search tool; works with or without a local model
  • Zero-config LAN discovery: one click finds LabFlow servers on your network — pairing still certificate-pinned
  • SOP uploads now extract searchable text automatically; earlier uploads are indexed on first search
1.6.0August 2026
  • Device-locked licensing: Ed25519-signed keys verified fully offline against a per-machine ID
  • 14-day trial with clock-rollback protection; expiry locks the app but never touches your data
  • Licence card in Settings: machine ID, plan, expiry, one-click activation
  • Activation gate and trial flows in both English and Arabic
1.5.0August 2026
  • Full dark theme across every screen, tuned for night-shift work — per user, not per installation
  • Theme toggle on login screen and in Settings; preference persists per account
  • Contrast pass over charts, tables and status badges in both themes
1.4.1August 2026
  • Polish release following full workflow recording: fixed demo-data edge cases and minor RTL layout issues
  • Report header alignment corrected in Arabic exports
1.4.0August 2026
  • Turnaround-time targets per test with SLA breach surfacing on the dashboard
  • Billing: invoices generated from cases, payment tracking, revenue summaries
  • Equipment module: calibration schedules, due-date alerts, maintenance history
  • Inventory: reagent stock levels with low-stock warnings
  • Critical-results board with live N/H/L flagging against reference ranges
1.3.0August 2026
  • Security hardening pass following an external-style expert review
  • Hash-chained, HMAC-keyed audit log with verification screen
  • Login lockout after repeated failures; session handling tightened
  • Encrypted backup format
1.2.0August 2026
  • Enterprise UI redesign: denser tables, consistent forms, calmer colour system
  • Accessibility pass: focus states, keyboard navigation, contrast
1.1.0August 2026

  • Setup wizard selects and configures the workspace on first run
1.0.0August 2026
